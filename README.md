# Alua

Alua je vyvojovy projekt pro Luanti. Prvni faze je maly serverovy mod, na kterem budeme postupne stavet vlastni herni mechaniky a AI agenta.

## Aktualni stav

Repozitar je pripraven jako jednoduchy Luanti mod.

Po aktivaci modu ve svete lze v chatu spustit:

```
/alua_test
```

Spravna odpoved:

```
Alua funguje. Hrac: <jmeno>
```

## Soubory

- `mod.conf` - metadata modu
- `init.lua` - vstupni bod modu

Dalsi kroky: zakladni diagnostika, NPC entita, vnimani okoli, akce a pozdeji napojeni na externi AI mozek.
